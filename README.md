Software to use [CANBed FD](https://www.seeedstudio.com/CANBed-FD-Arduino-CAN-FD-Development-Kit-p-4724.html) to read CAN data and drive gauges on a NB Miata

Used in conjunction with the [baseboard](https://github.com/crxguy52/canGagueDriver-baseBoard) to convert signals from 12 to 5V and vice versa
